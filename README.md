# Art to Anki

Generates Anki flashcards from a folder of art images. The script parses filenames (e.g., `Artist-Name-Artwork-Title--S.jpg`) to automatically create cards with the image on the front and details on the back.

## Usage

1. Install `genanki`:
   ```bash
   pip install genanki
   ```
2. Place your images in the `ART/` directory.
3. Run the script:
   ```bash
   python enhanced_art_to_anki.py
   ```
4. Import the generated `art_history_deck.apkg` into Anki.
